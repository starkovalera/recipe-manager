# Prototype 17 — Desktop Edit approved core

Status: approved low-fidelity behavior consolidated into a permanent artifact.

This prototype preserves the confirmed desktop Recipe Edit slice:

- one continuous page and one recipe-level draft;
- sticky left section rail with ordinary page scrolling and scrollspy intent;
- two-zone Basics layout;
- compact Cooking time and Servings inputs;
- Cooking time and Servings accept empty or positive whole-number values;
- Quantity remains optional and supports approved numeric expressions;
- visible Difficulty segments and whole-star Personal rating, each with Clear;
- compact desktop Ingredients rows with reorder, fixed Unit, required name, and trash;
- linked failed-Save summary, field/section errors, and rail error markers;
- centered desktop dirty-draft guard with Save, Discard, and Cancel;
- desktop Import Info remains under Overflow and is not a permanent action.

The Instructions, Cooking notes, and Nutrition sections are continuity placeholders only. Their editing behavior is not approved by this prototype.

Use the toolbar to switch among Normal, Validation, and Guard states.
