Approved · all mobile screens

Hierarchy-aware top bar

Root screens use title and contextual actions without Back. Nested screens use Back; after scroll they collapse to Back, a truncated title, and essential utilities. Recipe Detail adds identity and local modes only in its expanded state.

Fixed global destinations

Recipes, Collections, Notifications, and Profile surround a distinct central Add action. Recipe Detail stays inside Recipes; Admin stays inside Profile.

Approved

One modal layer above navigation

Add, Media, Overflow, Import Info, disclosures, and confirmations fully cover and disable the global bar. Sheets replace one another rather than stacking.

Compact header and corrected-B actions

The horizontal action row starts at the cover edge. View, Focus, and Edit form one group; Media and Overflow form the utility group. Desktop Import Info is an Overflow item, not a permanent button.

Edit Mode

Open desktop core prototype
Approved · desktop

Desktop Basics & Ingredients

One recipe-level draft, sticky section rail, ordinary scrolling, two semantic Basics zones, compact assessment controls, and desktop ingredient rows. Cooking time and Servings are empty or positive whole numbers.

Approved · desktop

Validation hierarchy

A failed global Save exposes a linked summary, section markers, and concise inline errors, then focuses the first invalid field. Aggregate ingredient limits stay at section level.

Approved · desktop

Dirty-draft guard

Back, browser Back, mode changes, page navigation, and Manage Media invoke one centered Save / Discard / Cancel decision. Media and Import Info do not.

Approved · mobile

Compact-from-entry mobile Edit

Back, truncated title, Save, and Overflow form the toolbar. A single-open accordion owns the sections; Media and Import Info stay in Overflow while the global application bar remains navigation-only.

Approved · mobile

Compact Ingredients + one-item sheet

The full summary button with chevron opens one focused ingredient editor. Rows keep the standard trash action; mobile has no reorder handle, drag interaction, or move commands.

Approved · mobile

Touch-oriented Basics controls

Source uses a checked selection sheet; Difficulty is direct; Personal rating uses 5 whole-value stars. Clear owns the unset state.

Approved · mobile

Mobile validation & guard

Failed Save links into accordion sections. The blocking guard uses Save changes, Discard changes, and Keep editing; safe dismissals retain the draft.

Preserved context

History

Comparison screens and earlier prototype iterations remain in the repository. They are evidence, not current direction. The gallery never silently replaces an approved image; a superseded decision will receive a new card and the former card will be relabeled.
