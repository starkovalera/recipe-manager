# Integrated Mobile Recipe Edit

Status: interactive baseline for continued section design

This isolated prototype combines the approved mobile Recipe Edit decisions without changing Prototypes 09–12:

- always-compact Recipe Detail header;
- `Back / truncated title / Save / Overflow`;
- Media and Import Info in Overflow while editing;
- one recipe-level draft and dirty-exit guard;
- single-open accordion sections;
- approved compact mobile ingredient rows and single-item editor;
- unchanged global mobile navigation.

The detailed forms for Cooking notes and Estimated nutrition are explicitly provisional. They exist only to make the accordion complete enough for the next design discussions.

Open `index.html` directly to review. Run `test_prototype.js` with the bundled Node and Playwright runtime for deterministic verification.
