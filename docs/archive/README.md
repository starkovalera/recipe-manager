# Documentation Archive

This directory preserves completed and superseded planning artifacts as historical snapshots. Archived documents do not define current scope or executable work.

Use [`../roadmap.md`](../roadmap.md) for current project status, [`../../design/roadmap.md`](../../design/roadmap.md) for Design, [`../architecture/production-roadmap.md`](../architecture/production-roadmap.md) for Development, and [`../future/`](../future/README.md) for unpromoted Future Capabilities.

Archive folders describe the original concern:

- `plans/` — completed or superseded execution plans;
- `architecture/` — superseded architecture snapshots;
- `product/` — superseded product and scope documents;
- `investigations/` — completed research snapshots;
- `reports/` — historical verification and status reports.

Links, file maps, checkboxes, and tool instructions inside an archived snapshot are historical and are not maintained as current repository instructions.
