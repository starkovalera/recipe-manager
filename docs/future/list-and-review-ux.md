# List and Review UX Improvements

Stage: Captured
First-version scope: reconcile with the Core Design Baseline before promotion

## Opportunities

- tag field limits, visible mutation errors, recipe counts, navigation, sorting, and search;
- ingredient field limits, insertion position, desktop reordering, and a future serving calculator;
- multiple Review Flag types and atomic bulk resolution;
- Import History versus notification/direct-job navigation;
- unavailable Import Job source-media fallbacks;
- pagination-aware selectors in Recipe editing;
- collection sorting and filters;
- distinct notification visuals with accessible text and status cues.

## Refinement rule

These opportunities touch active Design Domains. During Core Design Baseline work, either incorporate the behavior into first-version scope or leave it explicitly deferred here. Create Design issues before Development issues whenever interaction or information hierarchy remains unresolved.
